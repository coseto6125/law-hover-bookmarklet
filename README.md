# 法條懸停 · 書籤版（bookmarklet）

在**不安裝任何擴充功能或程式**的前提下，於全國法規資料庫頁面上就地顯示被引用的條文。

滑鼠移到「第七十七條之二」上，條文就出現在原地，視線不用離開正在讀的那一句。

**➜ [安裝頁面](https://coseto6125.github.io/law-hover-bookmarklet/)**（把按鈕拖到書籤列即可，不需安裝任何東西）

## 緣起與致謝

概念源自 [引線](https://yinxian.vercel.app/)（[@termcavetw](https://www.threads.net/@termcavetw) 開發的
Chrome 擴充功能），該產品把「看到法條，滑過去就好」這件事做得很好。

本專案**不是引線的移植、分支或衍生**，與其開發者無任何關係，也未參考其原始碼
（引線並未開源）。之所以獨立重寫，是因為擴充功能在許多企業資安控管下無法安裝，
而 bookmarklet 是該限制下唯一還能「在原網頁上就地作用」的途徑。

兩者的差異：

| | 引線（Chrome 擴充功能） | 本專案（書籤） |
|---|---|---|
| 安裝 | 需安裝擴充功能 | 只加一則書籤 |
| 生效方式 | 自動，永久 | 每頁點一次 |
| 適用範圍 | 任何網站、PDF | 僅 law.moj.gov.tw |
| 功能廣度 | 地方法規、函釋、歷史條文、PDF 等 | 僅條文懸停 |

**需求若能安裝擴充功能，請直接用引線，功能完整得多。**
本專案只解決「不能安裝任何東西」這一個處境。

## 為什麼是 bookmarklet

公司資安控管常見禁止安裝 Chrome 擴充功能。瀏覽器的同源政策使得
「純網站無法修改另一個網域的頁面」，因此要在 `law.moj.gov.tw` 原網頁上加功能，
唯一不需安裝的途徑就是 bookmarklet：它只是書籤列上的一則書籤。

## 為什麼不需要伺服器

`law.moj.gov.tw` 的 CSP 為 `connect-src 'self'`，禁止對外連線。
但因為條文本身就在同一個網域，腳本可直接向原站取得條文。

實測結果（2026-08）：

```
Content-Security-Policy: default-src 'self'; ... connect-src 'self' ...;
script-src 'nonce-...' 'strict-dynamic'; object-src 'none'
```

- `javascript:` 書籤在 Chrome/Firefox 皆豁免於 CSP，注入可行。
- 對外連線數為 **0**，開發者無伺服器，看不到任何查詢紀錄。

### 樣式為何不能用 inline style（踩過兩次的坑）

`style-src` 沒有 `'unsafe-inline'` 時，以下**全部**會被 Chrome 阻擋：

| 寫法 | 結果 |
|---|---|
| `el.setAttribute('style', ...)` | 阻擋 |
| `el.style.color = 'red'` | 阻擋 |
| `el.style.setProperty(...)` | 阻擋 |
| `<style>` 無 nonce | 阻擋 |
| `<style nonce="...">` 帶頁面 nonce | **允許** |
| 改寫既有樣式表的 `rule.style` | **允許** |

關鍵區分是「元素層級的 style」vs「樣式表規則層級的 style」，後者不算 inline style。
因此本專案所有樣式都寫成 class 規則，動態值（面板座標）以改寫規則內容達成，
顯示與隱藏則用 class 切換。`test/csp.js` 會攔截所有元素層級的 style 寫入並讓測試失敗，
避免此問題再次發生。

若原站未來移除 nonce，程式會退而把規則插入任何一張同源可寫入的既有樣式表。

## 功能

- 辨識法條引用並加上標記，滑鼠移上顯示條文全文
- 支援阿拉伯數字、全形數字、中文數字（第七十七條之二）與「之X」條號
- 定位到項、款，命中的項會標黃
- **裸條號**（「依第九十九條」「本法第五條」）自動指向當前頁面的法規，免搜尋
- 剝除公文前綴（「案建築法」「不受土地法」「另依」→ 建築法、土地法）
- 法規名稱容錯：「刑法」→ 中華民國刑法、官方名稱帶括號註記者亦可對上
- 網路不穩時自動重試兩次（公司 proxy 環境常見偶發中斷）
- 條號驗證失敗時不顯示條文，明講原因：**查不到比查錯安全**
- 同條文快取，不重複請求

## 開發

```bash
npm install           # 測試需要 jsdom；瀏覽器驗證需要 playwright
node build/build.js   # 產生 dist/lawhover.bookmarklet.txt 與 dist/install.html
npm test              # 全部測試
```

各測試檔用途：

| 檔案 | 驗證對象 | 需要網路 |
|---|---|---|
| `test/run.js` | 原始碼行為，用真實頁面 fixture | 否 |
| `test/csp.js` | CSP 相容性，攔截所有 inline style 寫入 | 否 |
| `test/dist.js` | 建置產物，含安裝頁兩個安裝路徑一致性 | 否 |
| `test/live.js` | 打包版對線上站台端到端 | 是 |
| `test/pcode.js` | 16 部法規的名稱→pcode 對照 | 是 |
| `test/browser.js` | 真實 Chrome，以實際書籤點擊路徑執行 | 是 |

建置會同時輸出到兩處：

- `dist/` 本地產物
- `docs/` GitHub Pages 來源，即線上安裝頁

安裝頁含可拖曳的按鈕與手動貼上兩條路徑，`test/dist.js` 會驗證兩者內容一致。

## 測試涵蓋

| 面向 | 項目 |
|---|---|
| 條號解析 | 阿拉伯／全形／中文數字、之X、項、款 |
| 裸條號 | 指向當前頁 pcode、本法自指詞、不與具名引用重疊 |
| 排除規則 | `<script>`／`<a>` 內不標記、無引用段落不更動 |
| 取文 | 真實頁面 fixture 解析、面板內容、項次高亮 |
| 隱私 | 所有請求皆同源、無第三方網域 |
| 快取 | 同條再查不重複請求 |

線上端到端（`test/live.js`，18 項）涵蓋四個情境：建築法裸條號取文、
跨法規具名引用（土地法，需經搜尋）、換一部法規確認未寫死、不存在條號的失敗行為。

名稱對照驗證（`test/pcode.js`，20 項）對 16 部法規實打線上搜尋。此項先前只在
建築法與土地法上驗過就當作完成，擴大抽查後發現「刑法」（官方全名為中華民國刑法）、
「都市計畫法臺灣省施行細則」（名稱帶括號註記）、
「建築技術規則建築設計施工編」（以「編」結尾，原本連辨識都沒辨識到）三種失敗，
已全數修正。

真實瀏覽器驗證（`test/browser.js`，27 項）在 Chromium 中以**使用者點擊書籤的實際路徑**執行。

這個區別很重要：頁面自身設定 `location.href='javascript:...'` 會被 CSP 的 `script-src` 擋下，
但使用者點擊書籤屬於瀏覽器發起的導覽，豁免於 CSP。前者實測會失敗（標記 0 處、
出現 `script-src-elem` 違規），後者正常（標記 74 處、零違規）。
測試以 CDP `Page.navigate` 模擬後者，才代表真實使用情境。

該測試同時涵蓋：重複點擊書籤不會重複標記或建立面板、五種頁面型態
（全文頁、單條頁、沿革頁、搜尋結果頁、首頁）皆無 CSP 違規與 JS 錯誤、
並以 computed style 確認樣式確實生效而非只是 class 掛上去。

## 限制

- **每換一頁要重點一次書籤**，不會自動生效。這是不安裝任何東西的代價。
- 僅在 `law.moj.gov.tw` 運作。其他網站因同源政策無法取得條文。
- 地方法規（22 縣市各自的系統）不在此版範圍。

## 資料來源

條文內容來自法務部全國法規資料庫，著作權歸屬原機關。
本工具僅提供查詢便利，不對條文的即時性與正確性負責，正式引用請以官方網站為準。
