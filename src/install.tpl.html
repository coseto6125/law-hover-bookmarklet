法條懸停 · 書籤版

不必安裝擴充功能，也能在全國法規資料庫上滑過去看條文。

適用情境：公司資安控管禁止安裝 Chrome 擴充功能與任何程式。 書籤版只是在書籤列多一則書籤，不寫入登錄檔、不安裝檔案、不需管理員權限。

安裝（Windows · Chrome / Edge）

  1. 按 Ctrl + Shift + B 叫出書籤列（若已顯示可略過）。
  2. 把下面這顆按鈕用滑鼠拖曳到書籤列上放開。
法條懸停
↑ 拖曳我到書籤列

拖不動的話，改用手動新增：在書籤列按右鍵 → 新增網頁，名稱填「法條懸停」， 網址貼上下面整段文字。

使用

  1. 開啟任一全國法規資料庫頁面，例如 law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0070109。
  2. 點一下書籤列上的「法條懸停」，右下角會顯示已標記幾處引用。
  3. 條文中的引用會出現紅色虛線底線，滑鼠移上去即顯示該條全文； 寫到第 X 項時會把那一項標黃。
與擴充功能版的差別：書籤版每換一頁要重點一次，不會自動生效。 這是不安裝任何東西所必須付出的代價。

為什麼這樣是安全的

項目說明
對外連線無。條文直接向你正在瀏覽的 law.moj.gov.tw 取得，連線從未離開該網域。
伺服器無。沒有屬於開發者的伺服器，開發者看不到任何查詢紀錄。
資料儲存無。快取只存在當前分頁的記憶體，關掉即消失。
安裝行為無。僅新增一則書籤，可隨時刪除，不留任何痕跡。

疑難排解

狀況處理
點了沒反應確認網址列是 https://law.moj.gov.tw/...。本工具僅在該站運作。
貼上網址後前面的 javascript: 不見了 瀏覽器的安全機制會在貼上時移除。請把游標移到最前面手動補上 javascript:。
顯示「查不到條文」 刻意設計：驗證失敗時寧可不顯示。查不到比查錯安全。請點面板內連結至原站確認。
公司鎖住書籤列那就真的無解，只能改用原站的查詢功能。
條文內容來自法務部全國法規資料庫，著作權歸屬原機關。
本工具僅提供查詢便利，不對條文的即時性與正確性負責，正式引用請以官方網站為準。
