概念源自「引線」，感謝 @termcavetw 是他先想到「看到法條，滑過去就好」這件事，並做成了 Chrome 擴充功能。

會有這個書籤版，是因為我把引線分享給太太時， 雖然覺得應該很好用，但她公司資安管控下無法安裝任何 Chrome 擴充功能。 於是在相同的思路下改寫成書籤，不需安裝就能用；也因為是書籤，順帶能在手機上使用。

☕ 支持引線作者 看看引線 能安裝擴充功能的話，也可以安裝「引線」比較看看；擴充功能能主動掃描，用起來更方便。
零安裝 · 無伺服器 · 零對外連線

看到法條，滑過去就好

在全國法規資料庫讀條文，遇到「第七十七條之二」還得另開視窗查。 這則書籤把那四個動作變成一個：條文出現在原地，視線不用離開正在讀的那一句。

法條懸停
用滑鼠拖曳這顆按鈕到書籤列
放開後書籤列會出現「法條懸停」。建議改名為「法條」，手機上才好叫出來。
用手機？
手機沒有書籤列，用法不同
拖不動或看不到書籤列？
先按 Ctrl+Shift+B 叫出書籤列
改用手動貼上（書籤列按右鍵 → 新增網頁）
貼上後若開頭的 javascript: 不見了，請手動補上。
範例

裝好之後長這樣

下面是模擬的法規頁面。把滑鼠移到紅色虛線上，條文就會出現，不用真的安裝也能先試。

law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0070109

第 25 條　建築物非經申請直轄市、縣（市）（局）主管建築機關之審查許可並發給執照，不得擅自建造或使用或拆除。但合於第七十八條及第九十八條規定者，不在此限。

二、案建築法第77條之2第1項規定，供公眾使用建築物之室內裝修應由開業建築師或專業設計技術人員設計。

四、另參照司法院釋字第748號解釋意旨辦理。

三、前項辦理時不受土地法第二十五條之限制，並依第九十九條規定辦理。

「第七十八條」這種沒寫法規名的裸條號也認得，會自動指向你正在看的那部法規。寫到第 X 項時，該項會標黃。釋字與憲判字同樣滑過去就顯示。
功能

認得懂公文的寫法

條號的寫法千奇百怪，這些都處理了。

各種條號寫法

阿拉伯數字、全形、中文數字（第七十七條之二）、之X 條號都認得，並可定位到第 X 項第 X 款。

讀得懂公文的寫法

「依第九十九條」這種沒寫法規名的裸條號會指向當前法規；「案建築法」「不受土地法」等前綴也會自動剝除。

這條改過沒有

條號標黃色代表修正過，一眼看出哪些條動過。滑過去看修正次數與年份，並可彈窗開啟立法院查當年的條文與修法理由。

釋字與憲判字

「釋字第 748 號」「115 年憲判字第 6 號」滑過去直接顯示解釋文與爭點，不用另開視窗。

中央與地方都能用

全國法規資料庫，以及全台 22 縣市的地方法規系統。同一則書籤，在哪個站就查哪個站。

在其他網站（如 Word 線上版、PDF、Google）點下去會顯示「僅在法規網站上運作」，不會動到那個頁面，也不會發出任何連線。

查不到就明講

條號驗證失敗時寧可不顯示並說明原因。查不到比查錯安全，顯示錯誤條文會導致誤引。

安全

為什麼公司資安擋不到

它不是程式、不是擴充功能，只是書籤列上的一個項目。

項目說明
安裝行為無　僅新增一則書籤，不寫入登錄檔、不需管理員權限，可隨時刪除且不留痕跡。
對外連線無　條文直接向你正在瀏覽的那個網站取得，連線從未離開該網域。
伺服器無　沒有屬於開發者的伺服器，開發者看不到任何查詢紀錄。
資料儲存無　快取只存在當前分頁的記憶體，關掉分頁即消失。
原始碼GitHub 公開，MIT 授權，可自行檢視與建置。

唯一的代價：每換一頁要重點一次書籤。它不會像擴充功能那樣自動生效，這是不安裝任何東西所必須付出的代價。

排除

遇到狀況

點開看處理方式。

點了書籤沒反應，畫面什麼都沒變

先確認網址列是 https://law.moj.gov.tw/...，本工具僅在該站運作，在其他網站點了不會有任何反應。

若網址正確，點下去後畫面最上方中央會出現一條綠色提示，告訴你標記了幾處引用，同時被標記的字會閃兩下黃色。若提示寫「沒有找到法條引用」，代表這一頁本來就沒有條號可標。

看不到書籤列，按鈕拖不上去

按 Ctrl+Shift+B 叫出書籤列（Mac 是 ⌘+Shift+B）。書籤列就是網址列正下方那一條。

還是不行的話，用上方安裝區的「手動貼上」：在書籤列按右鍵 → 新增網頁，名稱自取，網址貼上那段文字。

貼上網址後，開頭的 javascript: 不見了

這是瀏覽器的安全機制，貼上時會自動移除這段前綴，避免使用者被誘導貼入惡意程式。

請把游標移到網址最前面，手動補上 javascript:（含冒號），再儲存即可。

顯示「查不到條文」

這是刻意設計：抓回條文後會先驗證確實是該法規該條，驗證失敗就不顯示，並告訴你卡在哪一步。

查不到比查錯安全，顯示錯誤條文會導致誤引。請點面板內的連結到原站確認。網路不穩時會自動重試兩次，仍失敗才會顯示此訊息。

換一頁之後標記就消失了

正常。書籤只作用在點擊當下那一頁，每換一頁要重新點一次。

這是不安裝擴充功能所必須付出的代價。擴充功能能自動生效是因為它常駐在瀏覽器裡，而書籤沒有這個能力。

公司把書籤列鎖住了

若群組原則停用了書籤功能，那就真的無解，只能改用原站的查詢功能。

不過多數企業控管的對象是安裝程式與擴充功能，書籤通常不在管制範圍內，值得先試試。

這會不會把我看的公文內容傳出去

不會。本工具沒有屬於開發者的伺服器，也沒有任何對外連線。

查條文時唯一的連線，是向你正在瀏覽的 law.moj.gov.tw 索取該條條文，連線從未離開該網域，也不夾帶你正在看的內容。原始碼公開可自行檢視。

發現條文顯示錯誤，要怎麼回報

裝好之後畫面右下角有「✉ 回報問題」，或直接在條文面板底部點「這條顯示錯了」，後者會自動預選問題類型並帶入該條的原文與顯示內容。

回報表單會自動附上網址、解析結果與錯誤記錄，不必截圖也不必開開發者工具。你只需要貼上出問題的法條文句。也可直接寄到 cosetoenor@gmail.com。

書籤上為什麼沒有圖示

這是瀏覽器的設計，無解，但不影響功能。Chrome 是以「網頁網址」去對應圖示的，而 bookmarklet 的內容是 javascript: 開頭的一段程式碼，不是一個可以載入的網頁，沒有網址可供對應，所以拿不到任何圖示。

實測確認：本站的圖示 Chrome 確實有抓取並存下，但它不會套用到 javascript: 書籤上。一般網址書籤才有圖示。

建議把書籤命名短一點（例如「法條」），書籤列上就不會佔太多空間。

手機

在手機上使用

程式在手機完全可用，同一個書籤不必分版本。差別只在怎麼叫出它。

先在電腦上把書籤加好，再同步到手機。手機瀏覽器沒有書籤列，也無法拖曳， 直接在手機上建立這種書籤非常麻煩。電腦與手機登入同一個 Google 帳號即會自動同步。

1
在電腦上把書籤改名為「法條」 書籤上按右鍵 → 編輯。名稱要短且好打，因為手機上要靠打字叫出它。
2
確認電腦與手機的 Chrome 登入同一個帳號 書籤會自動同步，通常一分鐘內完成。
3
手機開啟全國法規資料庫的任一頁 用 Chrome 開啟，例如搜尋「建築法 全國法規資料庫」點進去。
4
在網址列輸入「法條」，從建議清單點選那則書籤 注意：不要按 Enter 送出，要點下方出現的書籤項目。這就是手機執行書籤的方式。
5
改用「點一下」代替滑鼠移入 手機沒有滑鼠，所以點紅色虛線就會顯示條文，點面板外面關閉。程式會自動偵測，不需設定。
約 15 秒

iPhone（Safari）也可以，但 Safari 的書籤同步走 iCloud。 在 Mac 上加好書籤後即會同步到 iPhone，操作方式相同：在網址列打書籤名稱後點選。

回報

發現問題歡迎告訴我

法條的寫法千變萬化，一定有沒考慮到的情況。顯示錯誤的資料比查不到更危險，如果您方便，順手回報可以幫助更多人。

直接在工具裡回報最快

裝好之後，畫面右下角會有「✉ 回報問題」。點下去會自動帶入網址、解析結果與錯誤記錄，不必截圖，也不必開開發者工具。

1
選問題類型 「沒有顯示資料」或「資料顯示錯誤」，兩者的排查方向不同。
2
貼上出問題的法條文句 直接從頁面複製整句貼上。這是最有用的線索，多數解析問題都能由原文重現。
3
送出 診斷資訊已自動帶入且可自行刪改，按「用 Email 回報」開啟郵件即可。
也可以直接寄信： cosetoenor@gmail.com 或 開 GitHub Issue

回報內容不含你正在瀏覽的公文。只有網址、本頁法規名稱、標記結果樣本與錯誤記錄，送出前你都看得到，也可以自行刪改。

發布前修掉的問題（技術細節，可略過）

發布前請兩位獨立的 AI 工程師做了兩輪程式碼審查，找出並修正 8 個會顯示錯誤法條的問題。這類錯誤最危險，因為使用者不會發現：

  • 連續條號綁錯法規：「人口販運防制法第三十二條、第三十三條」的後半段被當成你正在讀的那部法，顯示完全無關的條文。

緣起

與「引線」的關係

先把話說清楚，免得誤會。

本工具不是引線的移植或衍生，與其開發者無關，也未參考其原始碼（引線並未開源）。 只是在相同的思路下，用書籤重新實作，以解決「什麼都不能安裝」這個處境。

引線（Chrome 擴充功能）本工具（書籤）
安裝需安裝擴充功能只加一則書籤
生效方式自動，永久每頁點一次
手機不支援可用
適用範圍任何網站、PDF法規網站
功能廣度函釋、PDF、引用總覽、常用條文等條文、沿革、釋字
地方法規全台 22 縣市全台 22 縣市

能安裝擴充功能的話，也可以安裝「引線」比較看看——擴充功能能主動掃描， 不必每頁點一次，適用範圍也涵蓋任何網站與 PDF，還有整頁引用總覽與常用條文。 本工具是為「什麼都不能裝」的處境而做，唯一多出來的是手機可用。

兩者不必二選一：自己的電腦上裝引線，公司電腦或手機上用這則書籤。

若覺得這個想法有幫助，請支持引線作者。
